- 增强 SIGINT 中断响应：工作线程队列采用安全轮询机制，确保在海量文件扫描过程中可瞬间响应 Ctrl+C 安全退出。

## 2026-11-19 19:38:28 file/interval_file_op.py
- 新增固定间隔文件批处理工具 `interval_file_op.py`，支持按固定间隔采样删除或移动文件。
- 多维度排序支持：文件名（自然数字排序，如 1, 2, 10）、文件大小、修改日期、创建日期，支持升序与降序（--reverse）。

- 完善的安全性与异常处理：执行前展示受影响文件抽样表格及统计面板，强制终端人工输入 `y` 确认（支持输入 `l` 展开完整清单）；支持 `--dry-run` 模拟演练；自动处理 Windows 文件只读属性与异常跳过；提供双通道日志记录（UTF-8 文件日志 + 彩色终端交互）。
