# 变更日志 2026-11-20

## 2026-11-20 09:29:56 - interval_file_op.py 批处理多线程与参数核对紧凑展示升级

### 1. 紧凑型双列任务配置与参数核对面板 (`render_config_panel`)
- **参数来源显式核对**：在用户确认执行前展示任务配置面板，通过 `parse_user_specified_flags` 自动检测命令行传入的参数，清晰标注每一项为 `[用户]`（高亮绿色）或 `[默认]`（暗灰）。
- **紧凑双列无折行布局**：将任务配置重构为左列（目标目录、递归扫描、匹配规则、目录模式、文件数阈值、计划操作、输出目录等）与右列（采样规则、起始偏移、排序依据、排序方向、并发线程、运行模式、免确认选项等），适配 80 列终端宽度，单行对齐紧凑美观。
- **CLI 参数对称补充**：补充 `--no-recursive` 与 `--no-preserve-tree` 反向开关，便于命令行自由关闭默认启用的递归与层级保留行为。

### 2. 批量删除与移动操作全面多线程加速 (`execute_batch_action`)
- **并发线程池执行**：批处理阶段采用 `queue.Queue` 与动态工作线程池（由 `-t / --threads` 统一控制，最高 32 线程），彻底消除万级/十万级文件删除与移动的单线程 I/O 瓶颈。
- **并发重名与移动路径线程安全**：`resolve_destination` 引入互斥锁与动态预定路径集合（`reserved_destinations`），多线程并发移动重名文件追加 `_1`, `_2` 时互不竞争碰撞，确保无重名冲突与数据丢失。
- **实时吞吐指标与平滑反馈**：支持 Rich 动态进度条及控制台纯文本降级，实时展示每秒处理项数（项/秒）、已完成百分比与计数。
- **优雅的 Ctrl+C 中断清理**：捕获中断信号后及时通知工作线程安全退出，停止后续任务并输出已完成统计。
