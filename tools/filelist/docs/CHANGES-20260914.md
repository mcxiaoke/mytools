- **字号指示器对比度修复**：修复 Pico CSS v2 在 `<button>` 内部将 `--pico-color` 强制定义为纯白反色（`var(--pico-primary-inverse)`）导致在亮色背景下字号重置按钮（`#fontReset` / `.font-val`）出现“白底白字”无法看清的问题。重构字号控制器样式，改用显式语义文本色 `--fl-text` 并强化加粗（`font-weight: 600`），亮色模式下呈现深深灰色（`#1e293b`），暗黑模式下呈现浅白色（`#f1f5f9`）。

- **全站明暗模式对比度与视口视觉检查**：
  - 修复 CSS 选择器语法错误，全面兼顾手动暗黑模式类与系统 `prefers-color-scheme: dark` 媒体查询。
  - 清理表格列单元格的背景干扰（`td { background: transparent !important; }`），确保整行 Hover 高亮在所有列均匀呈现。
  - 经桌面端与移动端（400x840）真机渲染截图确认：字号缩放指示、搜索交互栏、面包屑路径及表格列表在明暗双模式下对比分明、排版稳固，全量测试与实机部署验证通过。

## WebUI 路线 A 重构：Pico.css + Alpine.js 极简免编译嵌入架构（2026-09-14 10:59 GMT+8）

- **技术栈全面升级**：采用轻量免编译（Zero-Build）架构，引入官方预编译压缩库：
  - **Pico.css v2**：纯语义化 CSS 框架，自带高质感现代设计、优雅暗黑模式自适应及响应式布局基础。
  - **Alpine.js v3**：声明式响应式框架，彻底告别以前 500+ 行手写原生 DOM 拼接（`innerHTML += ...`），以 `x-for`、`x-show`、`x-model` 实现清晰的数据驱动渲染。
- **后端资源组织与嵌入升级**：
  - `src/server.go` 升级为 `//go:embed web/*` 目录级嵌入，依旧保持单个独立二进制分发优势，完全脱离外部网络与公网 CDN。
  - 新增 `/static/` 高速静态托管路由，配置 `Cache-Control: public, max-age=86400` 缓存头，跨目录导航与页面刷新零网络往返延迟。
- **业务代码清晰分层解耦**：
  - `src/web/static/pico.min.css` & `src/web/static/alpine.min.js`：第三方标准库资产。
  - `src/web/static/app.css`：FileList 专属的主题色、移动端双行响应式布局与组件细化样式。
  - `src/web/static/app.js`：`filelistApp` Alpine 组件，封装路径解码、历史记录导航、目录/根挂载点加载、防抖搜索与 `<mark>` 高亮、多字段排序、字号缩放持久化、流式上传及全局拖拽上传监听。
  - `src/web/index.html`：极简纯语义 HTML 模板，代码量缩减至仅 150 行。
- **全量测试与实机验证**：全量 22 项 Playwright 端到端（E2E）测试用例 100% 通过（耗时 13.3s），并通过 `deploy.ps1` 部署至 `192.168.1.118:8787` 实测验证正常。

## WebUI 移动端 (400x840) 响应式适配、字号调节与一键部署（2026-09-14 10:43 GMT+8）

- **移动端两行式顶部导航布局**：针对小屏幕（<= 640px，特别是 400x840 手机屏幕），采用 CSS Flexbox `order` 属性将原本在同一行的导航元素重排为上下两行：
  - 第一行：左侧放置「📁 根目录」按钮（`order: 1`），右侧通过 `margin-left: auto` 放置字号缩放控制器（`order: 2`），两者并排仅占约 50% 宽度，即使放大字体也绝不换行挤压。
  - 第二行：搜索框独占整行（`order: 3; width: 100%`），提供充足的输入空间，搜索按钮和清除按钮布局平稳。
- **清除按钮位置调整**：将搜索框清除按钮 `[✕]` 调整至「搜索」按钮左侧，避免点击清除时触发搜索按钮跳动抖动。
- **基准字号与缩放控制器**：
  - 基准字号提升至 16px，对应等比调优图标尺寸、表格间距与字阶比例，改善 4K 等高分屏下的可读性。
  - 顶部增加字体缩放调节器（`[ A- ] [ 100% ] [ A+ ]`），范围支持 85% ~ 200%，基于 `localStorage` 跨刷新自动持久化。
- **表格列宽与截断优化**：表格增加 `th.actions-col` 样式控制，文件名称项引入 `.name-text` 文本溢出省略截断（`text-overflow: ellipsis`），确保超长文件名不会撑破移动端视图宽度。
- **E2E 自动化测试覆盖**：在 `navigation.spec.js` 中新增移动视口（400x840）与放大缩放测试用例，校验双行布局对齐及整个视口无水平滚动条（`scrollWidth <= clientWidth`）；并在 `run-e2e.ps1` 中加入源码变动自动检测与智能重新编译机制。
- **一键部署脚本**：新增 `deploy.ps1`，自动跨平台交叉编译 `linux/amd64` 二进制、SCP 上传至目标主机并通过 `install -m 755` 规避正在运行进程锁，最后平滑重启 `filelist.service`。

## 文件上传功能与同名冲突自动后缀编号（2026-09-14 09:42 GMT+8）

- **后端流式上传**：新增 `POST /api/upload` 接口，使用 `r.MultipartReader()` 与 `io.Copy` 将文件直接流式写入磁盘，支持局域网大文件传输并保持极低内存占用。
- **同名防覆盖策略**：文件落盘时检测同名冲突，自动以 `(1)`、`(2)` 等数字编号生成不冲突的新文件名，保障已有文件不被覆盖。
- **跨平台文件名安全与截断**：新增 `sanitizeFilename` 与 `truncateUTF8`，自动过滤/替换不同操作系统下的非法字符（`<>:"/\|?*` 与控制字符替换为 `_`），避开 Windows 保留设备名称（`CON`、`PRN`、`AUX`、`NUL`、`COM1-9` 等前缀 `_`），清除尾部点和空格，超长文件名在有效 UTF-8 边界截断并保留扩展名及冲突后缀预留空间。
- **目录安全与防越界**：限制仅在具体子目录下允许上传（根挂载点列表禁止直接上传），严格防路径穿越，校验目标目录有效性与 `withinRoot` 越界检测，自动过滤 `excludeFiles` 敏感文件。
- **前端 SPA 交互**：工具栏增加上传按钮，支持文件多选与页面拖拽上传，配合 `XMLHttpRequest` 实时展示上传进度百分比，上传成功后自动刷新目录列表。
- **配置项开关**：新增 `upload.enabled` 配置项（默认 `false`），保持默认只读的安全性。
- **工具函数解耦重构**：将与路由和状态无关的纯函数及通用辅助函数（路径越界校验、JSON响应、文件名安全清理、UTF-8安全截断、同名编号生成等）从 `server.go` 抽取至独立的 `utils.go`，对应单元测试归入 `utils_test.go`。
