# 变更记录 2026-11-07

## [2026-11-07 13:54:27] 移动端文件名展示与操作体验重构：收起平铺图标为统一更多操作菜单、支持两行自然折行显示

### 背景与问题根因
- **问题现象**：在移动端竖屏浏览器（如 360px ~ 412px 视口）中，目录列表中的长文件名被严重截断（如照片文件名 `DSC_20110203_15...`、长小说书名 `《八零:...`），用户无法辨识具体文件。
- **根因分析**：
  1. **操作栏多图标横向挤占屏幕空间**：桌面端原本在 `td.actions` 平铺展示的按钮多达 5~7 个（下载、在线播放、阅读器、文本编辑、复制直链、扫码、重命名、删除）；在手机小屏下，即使每个图标缩小至 26px，总宽度依然达 180px~210px，占去屏幕过半宽度，导致左侧 `td.name` 仅剩 90px~130px 可用空间，只能容纳 5~6 个汉字；
  2. **小屏幕触控防误触差**：在触摸屏上将多个微型图标紧凑排列极易误触危险操作（如点击阅读或复制时不慎误触删除或重命名）；
  3. **单行不折行强制截断**：原 CSS 样式对 `.name-text` 设置了 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`，超出一行的文件名会被强行截断，无法利用垂直空间展示完整书名或长编号。

### 修复与优化方案
1. **移动端收纳操作栏为单一更多操作按钮（Action Sheet 抽屉）**（`src/web/index.html`、`src/web/static/app.js`、`src/web/static/app.css`）：
   - **桌面端保持原样**：宽屏下使用 `.act-desktop` 继续平铺显示原有快捷操作图标，兼顾桌面大屏效率与已有选择器兼容；
   - **移动端收拢单一入口**：移动端视口（`max-width: 640px`）隐藏平铺按钮，仅展示一枚 `⋮`（更多操作）按钮，将 `td.actions` 单元格宽度从 ~200px 骤降至 38px~40px，**为文件名释放超过 160px 的横向空间**；
   - **现代化底部操作抽屉（Bottom Action Sheet）**：
     - 点击 `⋮` 按钮唤出平滑上滑的 Action Sheet 浮层抽屉；
     - 抽屉顶部展示图标、**100% 完整无截断的文件全名**、文件大小以及最后修改时间；
     - 动作列表采用符合人体工学的大触控热区（高 46px，图标 + 明确文本），操作清晰防误触；
     - 支持 Esc 键、点击遮罩或取消按钮关闭，操作后自动触发对应功能并收起。
2. **移动端文件名支持两行自然折行与多音节断字**（`src/web/static/app.css`）：
   - 在移动端媒体查询下，将 `td.name a .name-text` 改为多行弹性盒模式：
     - `white-space: normal`；
     - `word-break: break-all; overflow-wrap: anywhere;`（确保即使无空格的长文件名、相机编号、哈希值也能在边缘正常折行）；
     - `display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical;`（最多显示两行，超出在第二行末尾自然呈现省略号）；
     - 图标与首行基线微调对齐，保持列表垂直节奏整齐；
   - 释放出的 ~300px 横向宽度配合两行折行，可完整呈现 40+ 个汉字或 80+ 个英文字符，完全覆盖绝大多数小说书名与照片编号。
3. **端到端测试与质量保障**（`tests/e2e/specs/navigation.spec.js`）：
   - 新增 E2E 测试用例 `should collapse action icons to more button on mobile and open action sheet modal`，验证移动端视口下桌面图标隐藏、操作栏收紧至 40px 以内、文件名占满可用宽度、计算样式具备两行折行属性，并测试 Action Sheet 展开展示完整文件名及关闭流程；
   - 全量 48 项 E2E 测试与 Go 后端单元测试全部通过。
