## v0.2.0 - basePath / token / 真增量索引 / 安全配置（2026-09-06 20:53）

基于部署前评审（含实测漏洞验证）落地的增强。全部安全项可配置、默认取安全值，家庭内网开箱即用。

### 子目录反代（basePath）

- `server.basePath`（如 `/files`）：后端自行认识前缀，页面/API/下载链接自动带前缀，反代无需 rewrite
- 中间件 `stripBase` 剥离前缀；空值 = 根路径部署，行为不变
- 前端 `index.html` 注入 `BASE` 变量（运行时替换 `__FILELIST_BASE__` 占位符，favicon/首页链接同样带前缀）
- basePath 字符集白名单校验（拒绝 `..`、`?`、`<` 等）

### 可选 token 鉴权

- `server.token`：空 = 开放（默认）。设置后支持 `?token=`、`Authorization: Bearer`，校验通过后 Set-Cookie（HttpOnly/SameSite=Lax/Path=basePath），浏览器只加一次 `?token=`
- 401 区分页面（HTML 提示）与 API（JSON）；`subtle.ConstantTimeCompare` 防时序

### 真增量索引（替换"定时全量重建"）

- `entries` 改为 map[vpath]Entry；Entry 增加 gen 标记与预小写 lname/lpath（搜索免重复 ToLower）
- 目录 signature（mtime+size）未变 → 整棵子树跳过（不 ReadDir、不 stat 子文件）；全部 root 未变 → 单次 pass 仅每 root 一次 stat
- 差异写盘（tmp+rename，崩溃不损坏已有缓存）；持久化结构 v2（persistData{Version, Entries, Dirs}），旧版 idx 识别后自动重建
- 并发：扫描持读锁（搜索不阻塞），仅 merge 短写锁
- 权衡（DESIGN §2.3.4）：仅改写文件内容且 mtime/size 不变时，搜索元数据滞后到父目录变化；浏览始终实时。`incremental: false` 可退回全量

### maxDepth 真正生效

- 此前仅配置字段存在、walk 未使用（实测无效）。现按深度截断：`1` = 仅根目录下第一层，`0` = 无限

### 排除规则：新增文件级 + 浏览与搜索一致

- 新增 `index.excludeFiles`（glob，大小写不敏感），默认排除 `.env`、`*.key`、`id_rsa`、`.htpasswd`、`.DS_Store` 等敏感文件
- `ListDir`（实时浏览）应用与索引相同的排除规则，消除"搜不到但能浏览到"的不一致
- 默认值仅在配置缺省时注入；显式空列表可关闭

### 安全（默认安全、可配置关闭）

- **symlink 越界拦截**：`/raw` 先 `EvalSymlinks` 再校验仍在 root 内，否则 403（修复实测可读 root 外文件的问题）；索引从不跟随目录软链接；`security.allowOutsideSymlinks: true` 放行
- **html/svg 强制下载**：`.html/.htm/.xhtml/.svg/.svgz/.mhtml` 一律 `attachment`，全局 `X-Content-Type-Options: nosniff` + `Referrer-Policy`，阻断同源 stored XSS；`security.blockInlineHTML: false` 关闭

## 虚拟路径路由修复

### 问题描述

配置 `url: /` 时存在两个 bug：
1. roots 视图显示名使用 `filepath.Base(root.Path)`（磁盘目录名），点击后无法正确进入目录浏览
2. URL `/` 既是 roots 视图入口又是根目录内容路径，前端 `navigate()` 将 `/` 归一化为空串导致循环

### 修复方案

决定不支持配置 `url: /`，强制要求子路径 `/xxx`，从根源消除路由歧义。

### 变更文件

- **config.go**: 
  - 拒绝 `url: /`，返回明确错误提示使用子路径
  - 移除 root "/" 重排序逻辑
  - 新增按 URL 长度降序排序，确保最长前缀优先匹配（如 `/data/archive` 优先于 `/data`）
- **indexer.go**: 
  - 简化 `MapVirtualToReal`，移除 root "/" catch-all 第二轮匹配
  - 更新函数注释
- **server.go**: 
  - `handleRoots` 使用 URL 路径段作为显示名（`/data` → `data`），替代 `filepath.Base(root.Path)`
- **config.sample.yaml**: 更新注释，示例从 `url: /` 改为 `url: /files`
- **config_test.go** (新增): 8 个配置校验测试
  - 拒绝 root "/"、拒绝 `//`、接受子路径、尾部斜杠裁剪、自动补前导斜杠、空值拒绝、无 roots 拒绝
- **indexer_test.go** (新增): 5 个虚拟路径路由测试
  - 精确匹配、子路径映射、路径清洗（防遍历）、最长前缀优先、root "/" 不再作为 catch-all

## filelist - 文件目录索引与搜索 Web 服务

### 新建项目

- 初始化 Go 项目 `filelist`，实现文件目录索引与搜索 Web 服务
- **config.go**: YAML 配置解析，支持路径映射（URL → 磁盘路径）、端口、索引间隔等配置
- **indexer.go**: 增量索引引擎
  - 启动时全量 walk 所有配置根目录
  - 后台定时（可配置间隔）增量重建索引
  - 内存索引 + gob 磁盘持久化，重启后秒级恢复
  - 文件名搜索：大小写不敏感子串匹配 + 相关度评分排序
  - 目录列表：实时读取磁盘（os.ReadDir），目录优先 + 字母排序
- **server.go**: HTTP 服务
  - 嵌入式 Web UI（//go:embed）
  - 目录浏览 API（/api/list）
  - 搜索 API（/api/search）
  - 文件下载/预览（/raw/，支持 Content-Disposition 下载头）
  - 路径遍历防护（path.Clean + 根目录边界检查）
- **web/index.html**: 单页 Web UI
  - 目录浏览、面包屑导航、列排序
  - 搜索框（250ms 防抖）、搜索结果展示
  - 文件预览/下载、Esc 清除搜索
  - 响应式布局（移动端适配）
- **deploy/filelist.service**: Linux systemd 开机启动配置
- **Makefile**: 编译构建（支持 Linux/Windows 交叉编译）
- **config.yaml**: 默认配置模板

### 技术栈
- 语言: Go 1.26
- 唯一外部依赖: gopkg.in/yaml.v3
- 编译产物: 单二进制（~10MB），无运行时依赖
- 跨平台: Windows + Linux（CGO_ENABLED=0 交叉编译验证通过）
