- **独立纯前端单页阅读器（`reader.html`）**：

  - 支持通过 URL 参数接收目标文本文件路径（`?url=...&title=...`），也支持无参模式下直接拖拽或选取本地 `.txt` 离线阅读。

  - 章节级轻量按需渲染，内存消耗恒定，彻底杜绝数百万字大文件造成的 DOM 卡顿或崩溃；
  - 左侧滑出目录抽屉，支持章节名实时模糊搜索与当前阅读章节高亮/自动定位。
- **两级阅读位置持久化（localStorage）**：
  - 基于 URL 或文件特征指纹记录阅读章节与段落滚动百分比；
  - 页面刷新、重新选入文件或调整字号后均能无缝自动复位。
