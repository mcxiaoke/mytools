## 13:49:07 — 内置常见开发环境排除清单与配置合并机制

- 背景与原因：生产环境挂载大盘时，`msys64`、`Scoop`、`flutter`、`android-sdk`、`venv` 等开发环境与依赖缓存产生超过 150 万个碎片文件，导致索引内存膨胀至 4~5GB。原 `defaultExcludeDirs` 仅包含 5 个基础目录，且若用户配置了 `excludeDirs` 会导致默认排除被完全覆盖失效。
- `src/config.go`：
  - 新增 `BuiltinExcludeDirs`：内置常见开发环境、包管理、工具链、构建输出和 IDE 缓存目录清单（版本控制 `.git`/`.svn`/`.hg`；前端 `node_modules`/`.pnpm-store`/`.yarn`；Python `venv`/`.venv` 等；Java/Kotlin `.gradle`/`.m2`；Rust/Go `target`/`vendor`；移动端与 SDK `flutter`/`android-sdk`/`.dart_tool`/`Pods` 等；Windows 工具链 `msys64`/`msys32`/`cygwin`/`cygwin64`/`w64devkit`/`Scoop`/`ScoopApps`；构建产物 `bin`/`obj`/`.vs`/`.idea`/`.vscode` 等；系统卷 `$RECYCLE.BIN`/`System Volume Information`）。
  - `defaultExcludeDirs` 指向 `BuiltinExcludeDirs`，保持向后兼容。
  - 新增 `index.builtinExcludes` 开关配置项（默认 `true`）及 `BuiltinExcludesEnabled()` 辅助方法。
  - 新增 `mergeUniqueDirs`：大小写不敏感去重合并基础排除项与用户自定义排除项。
  - `LoadConfig()`：启用 `builtinExcludes` 时，自动将 `BuiltinExcludeDirs` 与用户自定义 `excludeDirs` 合并生效（不再粗暴覆盖），确保用户即使仅配了自定义项也能享有内置防护；显式配置 `builtinExcludes: false` 时允许完全退出内置名单。
- `src/main.go` & `config.sample.yaml`：
  - 更新默认配置文件生成模板与示例配置文件，增加 `builtinExcludes: true` 说明及排除目录合并注释。
- `src/config_test.go`：
  - 新增 `TestLoadConfig_BuiltinExcludesMerged`：验证自定义 `excludeDirs` 与内置排除正确合并去重。
  - 新增 `TestLoadConfig_BuiltinExcludesDisabled`：验证显式 `builtinExcludes: false` 时只生效用户项。
  - 新增 `TestLoadConfig_BuiltinExcludesDisabledEmpty`：验证 `builtinExcludes: false` 且 `excludeDirs: []` 时排除为空。
- 文档：
  - 新增 `docs/DESIGN-COMPACT-INDEX-20261008.md`：深入调研 Everything 内存机制（Parent Index + 连续切片 + String Arena + noscan 零 GC 成本），提出 FileList 新一代紧凑索引架构方案。
