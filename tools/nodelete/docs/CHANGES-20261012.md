# 变更记录 2026-10-12

## 2026-10-12 09:32:18 - 彻底移除 Drive 注册并解决后台挂起卡死问题

- **移除磁盘根目录注册（Drive 作用域）**：
  - 更新 `install-context-menu.ps1`，彻底移除 `HKCU:\Software\Classes\Drive\shell\FolderGuard` 注册项，并在安装和卸载时主动清理历史遗留的 Drive 项；
  - 仅保留普通文件夹（`Directory`）和文件夹内空白处（`Directory\Background`），防止对全盘误操作造成死锁。
- **重构并加固 `FolderGuard-Run.ps1`**：
  - 增加安全防御：显式拦截针对盘符根目录（如 `C:\`, `D:\`）的任何操作，直接弹出警告并拒绝执行；
  - 彻底根除卡死原因：原脚本在隐藏窗口启动时因参数传递问题容易进入 `Read-Host` 导致永久后台死锁，现改为全自包含执行流程，去除任何命令行交互挂起和 sleep 延迟；
  - 弹窗置顶保障：MessageBox 增加 `DefaultDesktopOnly` 置顶属性，确保提权弹窗始终浮于桌面最顶层，不被 Explorer 遮挡。

## 2026-10-12 09:22:47 - FolderGuard 右键层叠菜单实现与集成

- **新增 `install-context-menu.ps1`**：
  - 基于 HKCU 注册表为当前用户安装 Windows 资源管理器原生右键层叠菜单 `FolderGuard`。
  - 支持文件夹选中（`Directory`）、文件夹内空白处（`Directory\Background`）及磁盘驱动器根目录（`Drive`）。
  - 子菜单统一采用标准英文单词命名并清晰分栏（通过 `CommandFlags 0x20` 绘制分割线）：
    - `Protect Folder`、`Unprotect Folder`、`Toggle Protection`（NoDelete 标记防删机制）
    - `NTFS Lock`、`NTFS Lock (Recursive)`、`NTFS Unlock`、`NTFS Reset Permissions`（NTFS ACL 权限锁，带 `HasLUAShield` UAC 盾牌图标）
  - 支持 `-Uninstall` 一键彻底清理还原注册表配置；
  - 自动在 `temp/` 导出 `.reg` 注册表脚本备查。
- **新增 `FolderGuard-Run.ps1`**：
  - 为 `FolderGuard.ps1` 提供图形界面启动包装器，自动静默请求 UAC 提权并隐藏控制台黑框；
  - 执行完毕后使用原生 Win32 MessageBox 反馈结果，与 `NoDeleteGUI.exe` 体验保持高度一致。
- **更新 `README.md`**：
  - 补充右键层叠菜单的安装、使用与卸载说明。
