### 3. 机械守卫接线（新增脚本与 CI）

- `scripts/verify.ps1`：**单一入口**——缩回开关构建 → 完整构建（最后落盘，体积测的就是它）→
  `cargo test --all-targets` → `clippy -D warnings` → 分层守卫 → 体积守卫 → Defender 归档。
  任一步失败即就地停下；结尾复位退出码，避免"不阻断"的步骤污染 CI 状态。
- `scripts/check_size.ps1`：体积守卫（250–750 KB）+ 归档 `size.txt` / `deps.json`
  （改用 `cargo metadata` JSON，弃用 `cargo tree` 树形字符——后者在 PS 5.1 + 中文代码页下会静默失效）。
- `scripts/gen_manifest.ps1`：落地 `TESTING.md` §4 的 `updater.manifest` 生成脚本
  （分隔符归一化 + 保留名排除 + UTF-8 无 BOM + LF）。
- `.github/workflows/ci.yml`：**项目内**的版本化流水线定义（`windows-latest` 上跑 `verify.ps1`）。
  ⚠️ Actions 只读仓库根的 `.github/workflows/`，而本仓库是 monorepo；
  要真正激活需把该文件放到 `<repo>/.github/workflows/better-updater.yml`（`paths` 已限定到本项目）。
- `docs/artifacts/`：归档 `size.txt`（422.5 KB）、`deps.json`、`test-summary.txt`、`defender-scan.txt`
