- **事务子系统**（TRANSACTION §3）：`ReplaceFileW` + 三处 MkdirAll + 错误码分类重试（32/5/1175/1176 可重试，1177 立即回滚）、备份对账式回滚（`restore_from` 唯一还原例程）、GEN 隔离、陈世代 GC、`--previous-ttl-days` 保留上一版 + `_meta.txt`（ADDED 取自权威 NEW 集合）。
