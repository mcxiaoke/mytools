### 交付范围

- **完整启动序列**（DESIGN §4 唯一权威流程）：写权限预检 → 取锁 → UAC 提权 → 影子分身 → L3 崩溃恢复 → 无损预检 → 等待目标进程 → 计划落盘（Journal PLANNED + fsync）→ 事务替换 → 提交前自检 → COMMITTED → 收尾（state 原子写 / `_meta.txt` / 备份转移 previous）→ 拉起主程序 → 自改名 `.del`。
- **事务子系统**（TRANSACTION §3）：`ReplaceFileW` + 三处 MkdirAll + 错误码分类重试（32/5/1175/1176 可重试，1177 立即回滚）、备份对账式回滚（`restore_from` 唯一还原例程）、GEN 隔离、陈世代 GC、`--previous-ttl-days` 保留上一版 + `_meta.txt`（ADDED 取自权威 NEW 集合）。
- **三层恢复**：L1 进程内回滚 + L3 冷启动自愈 + `--recover` 模式（含 `--pid` 等待、按需拉起）。**L2 看门狗按首发范围延后**，以"调用方启动自检同步执行 `--recover`"硬性契约兜底（TRANSACTION §2.3）。
- **无损预检**（DESIGN §5 全 15 项）：单句柄锁定（`FILE_SHARE_READ` + 文件映射验签，I8）、Ed25519 签名闭环（本构建公钥列表为空 = unsigned-build，仅内部/调试用）、SHA256、压缩方法约束、strip + 大小写不敏感去重、Zip Slip、包清单 `updater.manifest`、版本/降级防护（`updater.manifest` + `.updater/state`）、`--require`、物理路径分级校验（Junction/Symlink 越界拒绝）、zip bomb 双层（声明值预筛 2000:1 + 流式权威计数）、磁盘空间。
- **保护语义**（DESIGN §7）：`.updatekeep` 三类规则 + 自研 glob、内部保留名两层拦截（planner + apply）、updater 自身兜底保护、`to_verbatim` 四条前置规范化单一路径。
- **进程与运行期**（RUNTIME）：句柄等待（87/5 分流 + 映像路径日志核验）、ShellExecuteExW 提权（防递归守卫）、explorer 令牌降权（Session 0 拒绝拉起、1314 容灾、显式环境块）、影子 Worker 自更新（`%LOCALAPPDATA%\<name>-updater\<hash8>\runtime\`，有序候选 + DRIVE_FIXED 校验）、重启删除登记、Restart Manager 只读诊断（feature `restart-manager`，默认开）。
- **对外契约**（CONTRACT §2）：全部 CLI 参数、退出码 0/1/2/3、END 终止行、模式必填矩阵、`--args` 原文豁免、`quote_arg` argv 重建。**首发延后项**：`--rollback-previous` 与 `--watchdog` 传入时明确报错退出 2（不静默忽略）；`--verify-authenticode` 在无 authenticode feature 的构建中 fail-closed 拒绝。
