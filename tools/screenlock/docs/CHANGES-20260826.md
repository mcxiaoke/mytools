# 2026-08-26

- 10:16 六项功能增强（备份：temp/backups/20260826-100244/）：
  - **防误锁（全屏/演示自动暂停 + 暂停计时）**：`IdleDetector` 新增 `IsSystemBusy()`（P/Invoke `SHQueryUserNotificationState`，全屏游戏/演示模式/忙碌时挂起触发）；新增 `ShouldSuspend` 回调与有效空闲时间内部累计（挂起期间冻结计时，检测到输入立即归零），托盘菜单新增"暂停计时"（30 分钟 / 1 小时 / 恢复），暂停期间不触发也不预警。
  - **锁定前预警**：`IdleDetector` 新增 `WarnBefore` 与 `Warning` 事件，空闲达到阈值前 30 秒弹托盘气泡提醒，用户活动后预警状态自动复位。
  - **IdleMinutes 支持 0=禁用**：`AppSettings.Merge` 允许 0；`IdleDetector.OnTick` 阈值 <=0 直接跳过；托盘"空闲锁定"子菜单可选 禁用/1/3/5/10/15/30 分钟并带勾选态，修改即保存配置。
  - **PIN 哈希升级 PBKDF2**：`PinService.ComputeHash` 改为 `Rfc2898DeriveBytes`(PBKDF2-SHA256, 100000 次迭代)，存储格式 `pbkdf2$iter$hash`；校验兼容旧版单轮 SHA256，旧哈希验证成功后透明升级并由 `LockController.PersistPinUpgrade` 写回配置。
  - **RDP 断开锁定**：`OnSessionSwitch` 新增 `RemoteDisconnect` 分支，远程会话断开时立即 `LockSafe()`。
  - **日志轮转**：`LogError` 写入前检查 log.txt 超过 1MB 则删除重建。
  - **托盘菜单增强**：新增 开机自启开关（勾选同步注册表+配置）、空闲锁定时长选择、暂停计时子菜单；托盘 Tooltip 反映当前状态（暂停至 HH:mm / 已禁用 / 空闲 N 分钟）。
  - **行为调整**：移除睡眠唤醒后按原始空闲时间立即锁定的逻辑（会话解锁/计时重置机制已覆盖，且避免解锁 Windows 后重复输 PIN）；`IdleDetector` 改为内部累计有效空闲时间。

- 09:50 修复 Windows 锁屏/解锁后应用重复锁定的问题：
  - `App.xaml.cs`：新增 `SystemEvents.SessionSwitch` 监听，会话锁定（SessionLock）时挂起空闲计时（`_sessionLocked = true` + `Idle.Suspend()`），会话解锁（SessionUnlock）时重置计时（`Idle.Reset()`）；`OnIdleThresholdReached` 在会话锁定期间不再触发锁定；退出时取消事件订阅。
  - `Services/IdleDetector.cs`：新增 `Suspend()` 方法用于暂停阈值触发。
  - 效果：Windows 锁屏期间本应用不再触发 PIN 锁定，解锁后计时重新开始，无需重复输入 PIN。
