# 变更记录

## 2026-08-24 18:20 — 便携模式：exe 同目录 config.json 优先

- `ConfigService`：启动时若 exe 同目录存在 `config.json` 则进入便携模式，读写均使用该文件；否则回退 `%AppData%\ScreenLock\config.json`
- Reload Config 时若检测到同目录出现 config.json 会自动切换为便携模式
- 托盘"打开配置目录"、日志路径跟随当前生效的配置目录

## 2026-08-24 18:05 — 高分屏 DPI 适配

- `app.manifest`：DPI-unaware 改为 **system DPI aware**（`dpiAware=true`），高分屏下界面文字清晰不发虚；另加 longPathAware
- `LockWindow`：新增 `OnSourceInitialized`，用 Win32 `SetWindowPos` 按物理像素精确放置窗口，保证多屏/混合缩放下锁屏无死角覆盖（WPF 内容自动随客户端区域拉伸）

## 2026-08-24 17:52 — 接入应用图标

- `Assets\Icon.ico` 设为 exe 图标（ApplicationIcon），并以 pack resource 内嵌
- 托盘图标改用应用图标，加载失败时回退系统盾牌图标

## 2026-08-24 17:40 — 修复首次运行/验 PIN 窗口按钮被裁剪

- `FirstRunWindow` / `VerifyPinWindow` 高度写死导致确认按钮在部分 DPI 下不可见，改为 `SizeToContent="Height"` 自适应
- 两个窗口均支持回车：PIN1→PIN2→确定；验 PIN 窗口回车直接提交

## 2026-08-24 17:24 — ScreenLock v0.1.0 初始实现

按 `docs/DESIGN.md` 完成 S1–S5 全部开发，编译通过（0 警告 0 错误），冒烟测试启动正常。

### 新增

- **项目**：`src/ScreenLock.csproj` — .NET Framework 4.8 WPF + WinForms（托盘），SDK 风格工程；`app.manifest` 关闭 DPI 感知以简化多显示器坐标处理
- **配置**：`Services/ConfigService.cs` + 内置轻量 JSON 解析器（弃用 JavaScriptSerializer，其依赖 System.Web 与 WPF 标记编译器冲突）；配置位于 `%AppData%\ScreenLock\config.json`
- **闲时检测**：`Services/IdleDetector.cs` — `GetLastInputInfo` 每 1s 轮询，含 TickCount 回绕处理
- **键盘拦截**：`Services/KeyboardBlocker.cs` — WH_KEYBOARD_LL 低级钩子；锁定期间拦截 Win 全系、Alt+Tab/Esc/F4/Space、Ctrl+Esc，放行数字/退格/回车/Shift 供 PIN 输入
- **PIN 安全**：`Services/PinService.cs` — SHA256+随机盐哈希存储、固定时间比较防时序攻击；`PinGuard` 防暴力：错 5 次后每次递增 30s 惩罚倒计时
- **锁定控制**：`Services/LockController.cs` — 状态机，多显示器每屏一个 LockWindow，主屏承载 PIN 输入
- **锁屏界面**：`Views/LockWindow.xaml` — 半透明全屏置顶窗，500ms SetWindowPos 保活、失焦自动抢回焦点、WS_EX_TOOLWINDOW 从 Alt+Tab 隐藏
- **首次运行向导 / 退出验 PIN**：`Views/FirstRunWindow.xaml`、`Views/VerifyPinWindow.xaml`
- **自启管理**：`Services/AutoStartService.cs` — HKCU Run 键同步，随 Reload Config 生效
- **主程序**：`App.xaml(.cs)` — Mutex 单实例、托盘菜单（立即锁定/Reload Config/打开配置目录/退出需 PIN）、睡眠唤醒超阈值立即锁定、未处理异常写 `%AppData%\ScreenLock\log.txt`

### 说明

- PIN 明文不落盘；修改 PIN 目前需删除 config.json 中 PinHash/PinSalt 字段后重启重新设置（一期未做修改 PIN 的 UI）
- Ctrl+Alt+Del 为系统安全边界无法拦截，详见 DESIGN.md §8

### 测试建议

1. 启动 → 设置 PIN → 托盘出现盾牌图标
2. 手动改 `IdleMinutes` 为 0 后 reload 不生效（有下限保护），改为 1 分钟测试闲时锁定
3. 锁定后验证：Win 键/Alt+Tab/Alt+F4 失效、数字可输入、错误 PIN 提示、正确 PIN 解锁并重置计时
