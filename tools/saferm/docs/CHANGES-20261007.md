# CHANGES

> 记录重要代码变动的重点摘要（最新在最上面）。

## 2026-10-07 12:46:57 — 全量国际化（中英双语，go-i18n）

- 新增 `internal/i18n` 包装包：`T`/`E`/`LocalizedError` 本地化入口、`Init`/`SetLang`/`Lang` 语言管理、平台语言检测（Windows 用 `GetUserPreferredUILanguages`，Unix 用 `LANGUAGE`/`LC_ALL`/`LC_MESSAGES`/`LANG`）；`SAFERM_LANG` 环境变量可强制指定语言。
- 语言资源内嵌二进制（`go:embed`）：`internal/i18n/locales/active.zh-CN.toml` 由 `goi18n extract` 从调用点的中文默认文案自动抽取（源语言 = 中文），`en.toml` 为手工翻译，含英文复数（one/other）。
- 全部用户可见硬编码字符串（约 150 条）替换为 `goi18n.Message{ID, Other}` 字面量 + `i18n.T(...)`：覆盖 `cmd/saferm`（app/where/rmcompat/config、两段帮助全文）与 `internal/{config,guard,trash,ui,volume,platform}`；纯注释不涉及。`main.go` 启动时调用 `i18n.Init()`。
- 行为说明：
  - 中文系统默认中文、其它语言默认英文；未初始化（单元测试直驱各包）时默认中文，与既有中文断言兼容。
  - `fmt.Errorf("%w")` 的文案改走模板插值后不再保留包装链——核查过无任何 `errors.Is/As` 依赖这些文案，`ui.ErrNonInteractive` 哨兵改用 `i18n.LocalizedError`（渲染时才取语言，实例身份不变）。
  - 包级持有本地化文案的变量（rm 兼容参数提示表）改为惰性函数，避免在 `Init` 之前被求值成固定中文。
- 新增依赖：`github.com/nicksnyder/go-i18n/v2 v2.6.1`、`golang.org/x/text`；TOML 解码复用已有 `go-toml/v2`（v2.6 需手动注册 unmarshaler）。
- 新增测试：`internal/i18n/i18n_test.go`（语言切换、缺失键回退中文、英文复数、模板插值、两语言键集一致性校验）。
- 测试脚本加固：`tests/run-e2e.ps1` / `run-e2e.sh` 设 `SAFERM_LANG=zh-CN`，使断言在非中文机器上也成立。
- 文档：README 新增「多语言」一节。
- 验证：`go vet`、`gofmt` 干净；`go test ./...` 9 个包全绿；e2e 黑盒 59/59 通过；二进制在 `SAFERM_LANG=en` / 默认（中文系统）下输出实测正确。
