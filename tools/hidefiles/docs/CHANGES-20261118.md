# 变更记录 2026-11-18

### 2026-11-18 13:38:09 - 加密与解密凭据权限严格区分，加密场景禁用恢复码

- **PasswordDialog 区分凭据权限（`allowRecovery` 标志）**：
  - `PasswordDialog` 构造函数新增 `allowRecovery: bool` 标志（默认为 `true`）。
  - 当 `allowRecovery = false` 时（加密解锁/管理操作），弹窗标题为“输入密码”，提示语为“加密文件需要使用主密码，请输入密码：”，**彻底隐藏“使用恢复码”复选框与恢复码输入区**，高度自适应收窄至 280px。
  - 当 `allowRecovery = true` 时（解密场景），弹窗标题为“解密验证”，保留密码与 52 位紧急恢复码切换输入。
- **加密前置流程闭环**：
  - 未设置密码时点击加密：不再弹 messagebox 跳转设置页，改为直接原地弹出 `PasswordDialogMode.Set`（设置主密码弹窗，两次输入确认），设置成功后自动无缝继续执行加密。
  - 已设置密码但在新会话中点击加密：弹出纯密码解锁窗口（禁用恢复码），输密解锁后本次会话自动缓存，后续所有加解密免密进行。
- **验证**：全部 60 项单元测试通过，项目构建 0 错误 0 警告。

### 2026-11-18 13:02:33 - 结构与整体加密严格隔离、通用密码弹窗、复选框尺寸、扩展名规则及便携模式支持

- **结构与整体加密隔离（无自动降级/混淆）**：
  - `FileObfuscator.RestoreFile` 新增 `expectedMode` 参数：在“结构加密”工作台尝试解密整体加密文件、或在“整体加密”工作台解密结构加密文件时，直接明确报错拒绝处理，避免模式混用。
  - `ObfuscateFile` 在结构加密遇到不支持或解析失败的格式时，直接记录错误并跳过，绝不自动 fallback 到整体加密，批量任务正常继续处理其余文件。
  - 去除 `StructureLocator` 中过时的“兜底降级”注释。
- **通用密码对话框（PasswordDialog）**：
  - 新增 `PasswordDialog`，统一覆盖“设置密码”（双次密码确认防输错）、“修改密码”（当前密码验证 + 双次新密码确认）与“安全验证”（支持密码与 52 位恢复码输入）。
  - 设置页彻底移除单行明文/明文输入框，改为只显示当前密码状态与“设置密码 / 修改密码 / 清除密码”弹窗触发按钮。
- **界面第一列复选框显示优化**：
  - `StructFileGrid` 与 `SecureFileGrid` 第一列宽由 42 增加至 50，并清除内边距与外边距，确保 CheckBox 方框完整显示不被裁剪。
- **文件扩展名规则扩展**：
  - `HideFilesConfig` 规则列表新增 `Documents`（文档：`.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.txt`, `.md`）与 `Others`（其它：`.exe`, `.dll`, `.iso`, `.bin`, `.apk`, `.dmg`, `.db`）。
  - 自动向后兼容：读取既有配置文件时自动补齐缺失的 Documents 与 Others 规则。
  - 格式伪装列表对通用通配格式增加清晰友好展示。
- **便携模式（Portable Mode）支持**：
  - 参考 CarroDesk 实现自适应数据目录解析：检测程序所在目录的 `portable.ini` 标记或 `app_data/` 目录；若存在则启用便携模式，数据内聚存储于 `app_data/config.json`；否则使用 `%APPDATA%\HideFiles\config.json`。
  - 支持 `HIDEFILES_DATA_DIR` 环境变量与 `DataDirOverride` 测试注入。
  - 设置页与关于页新增“运行模式与数据存储”展示与“打开目录”快捷按钮。
- **验证**：全部 60 项单元测试（含 5 项新增测试）全部通过，构建 0 错误 0 警告。
