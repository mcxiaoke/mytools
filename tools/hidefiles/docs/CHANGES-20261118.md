## 22:24:10 修复标签页内容区鼠标误显示为手形（`App.xaml`）

- 根因：`MainTabItemStyle` 在 `TabItem` 上设了 `Cursor="Hand"`。`Cursor` 是可继承依赖属性，
  标签头设手形后，各标签（混淆/设置/关于）下方内容区里的 Grid/ScrollViewer/TextBlock 等
  也继承了手形光标，但这些区域并无点击动作，造成误导。
- 修复：删除该 `Cursor="Hand"` Setter。按要求不在任何位置另行设置光标，全界面统一用系统默认箭头。
- 备份：`temp/backups/App.xaml.20261118_222329.bak`。

## 21:05:00 界面二轮调整：修复 Tab 圆角、设置页全部单行、行距与间距优化

**1. 修复 Tab「左圆右直角」（`App.xaml`）**
- 根因：`TabItem` 用 `Margin="0,0,6,0"` 制造标签间距时，WPF 会把 `TabItem` 的内容区域压缩掉右侧 6px，
  而 `TabBorder` 的 `CornerRadius` 仍按完整宽度绘制 → 右侧圆弧被裁掉，只剩垂直直角。
- 像素证据（150% DPI，逐行统计强调色外接范围）：修复前右边缘每行恒定内缩 9px（纯直角），
  左边缘 9→0 平滑过渡（圆弧）；修复后左右均为 9→0，完全对称。
- 修复：`TabItem.Margin` 归零，间距改由模板内一层透明 `TabGap`（`Padding="6,0,0,0"`）承担。

**2. 设置页全部单行化（`MainWindow.xaml`）**
- 密码设置：1 行。中间弹性区平时放说明文案，刚设完密码时整段换成「恢复码 + 复制」。
- 数据存储：1 行。`目录 + 路径框 + 便携提示` 与「打开目录」同排；完整路径放 `ToolTip`。
- 混淆文件名：1 行。标题 + 头部长度下拉框 + 两个复选框同排。
- 目录名伪装：1 行（上一轮已完成）。
- 右键菜单：1 行。说明文字移到标题右侧，按钮右对齐并垂直居中（不再与整行高度错位）。
- 格式规则：标题行内嵌「恢复默认 / 保存设置」，六个分组两列三行。

**3. 间距与内边距（`SettingsCardStyle`）**
- 卡片 `Padding` 12,9 → **16,12**；卡片间距 `Margin` 6 → **12**。
- 格式规则行上下留白 `Padding` 0,2 → **0,7**，实测行距 **39.3px**（改前约 24px，明显偏挤）。
- 后缀输入框 54×20 → **60×24**，与放宽后的行高匹配。

**4. 验证（`Qa.cs` 新增断言，共 68 项）**
- Tab 四角对称：渲染成位图后比较「首行」与「中线」的左右内缩量，要求左右均 >2px 且差值 <=2.5px
  （修复前右侧为 0，会直接失败）。另断言 `TabItem.Margin.Right == 0` 防止回归。
- 前 5 个分组高度 <=72px（实测 57/57/57/57/57），全部单行。
- 卡片间距 >=10px（实测 12）、`Padding` 左右 >=14 且上下 >=10（实测 16,12）。
- 格式规则行距：两列布局按 Y 分桶后测相邻行距，要求 3 行且最小行距 >=26px（实测 39.3px）。
- 恢复码状态：正常态显示说明文案，赋值恢复码后说明让位、恢复码框出现，且整页仍一屏可见（滚动比 0.91）。
