# 2026-11-18 变更摘要

## 19:49:54 修复改应用名后启动崩溃（XamlParseException / FileNotFoundException: HideFilesApp）

- 根因：`HideFiles.App.csproj` 的 `<AssemblyName>` 已从 `HideFilesApp` 改为 `CarroCasket`，但 XAML 中 pack URI 仍引用旧程序集名 `HideFilesApp`，BAML 加载图标资源时找不到程序集。
- 修改：将 4 处 `pack://application:,,,/HideFilesApp;component/Assets/Icon/AppIcon.png` 统一改为 `.../CarroCasket;component/...`：
  - `src/HideFiles.App/MainWindow.xaml`（窗口 Icon、TitleBar BitmapImage、关于页 Image 共 3 处）
  - `src/HideFiles.App/Views/PasswordDialog.xaml`（窗口 Icon 1 处）
- 验证：全局搜索无 `HideFilesApp` 残留；`dotnet build src/HideFiles.App/HideFiles.App.csproj -c Debug` 成功，0 警告 0 错误，输出 `CarroCasket.dll`。
