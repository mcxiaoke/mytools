# 2026-11-19 变更摘要

## 22:29:02 目录扫描与文件加载异步化、模态进度弹窗与批量渲染优化（批次 1）

### 1. 扫描与元数据分析异步并发化（消除 UI 冻结与假死）
- **安全递归枚举**：使用 .NET 8 `EnumerationOptions`（`RecurseSubdirectories = true`, `IgnoreInaccessible = true`, `AttributesToSkip = ReparsePoint`），自动跳过受保护系统目录和软链接，杜绝深层递归抛出权限异常崩溃。
- **并发 Inspect 提速**：引入 `Parallel.ForEachAsync`（并发度 2~8）并发执行 `Inspect` 文件嗅探，数千个文件的元数据读取与头尾魔数校验耗时缩短 3~5 倍。
- **异步全流程**：`MainViewModel.AddPathsAsync` 将 I/O 和分析任务移出 UI 线程至后台线程池，主界面不再发生任何白屏未响应。少量常规文件（<20 且无目录）走快速同步分支，零延迟即时响应。

### 2. 模态扫描进度对话框（ScanProgressDialog）
- **UI 对话框组件**：新建 `ScanProgressDialog`（基于 `Wpf.Ui.Controls.FluentWindow`，与 Mica 材质、暗黑/明亮主题统一）。
- **实时进度反馈**：
  - 搜索阶段：展示正在搜索的当前目录路径与已发现文件数；
  - 分析阶段：显示确定性进度条、当前处理文件名、当前文件数/总文件数以及百分比；
  - 取消控制：提供“取消”按钮，绑定 `CancellationToken`，可随时优雅中断扫描，并保留已解析项。

### 3. UI 批量渲染优化与 DataGrid 虚拟化加固
- **批量数据更新**：引入 `ObservableRangeCollection<T>`，支持 `AddRange` 并在批量注入后仅触发单次 `Reset` 通知，彻底消除 5,000+ 个文件逐项 `Add` 引发的数千次 WPF 布局重绘风暴。
- **DataGrid 虚拟化**：在 `StructFileGrid` 与 `SecureFileGrid` 显式开启行虚拟化、容器循环复用（Recycling）与像素级平滑滚动（Pixel ScrollUnit），长列表滚动帧率稳定。

## 10:23:29 核心安全加固、解密单遍 I/O 优化、路径与品牌统一、关于页居中与任务取消支持

### 1. 安全加固：移除单轮哈希 PinHash 与 fallback 机制
- **移除 PinHash**：彻底移除 `HideFilesConfig` 中的 `PinHash` 属性及 `HashPin` / `PinSalt` 方法。杜绝配置文件泄露后被 GPU 高速离线暴破弱口令绕过 PBKDF2 的隐患；密码验证统一以能否成功解密 `WrappedMasterKey`（AES-256-GCM 认证标签常时比较）为唯一准则。
- **移除 fallbackMasterKey**：从 `V2Crypto.ResolveMasterKey`、`V2Container.Read`、`V2Tail.ReadFooter`、`FileObfuscator.RestoreFile` 及 `BatchProcessor.RestoreBatch` 中彻底移除 `fallbackMasterKey` 参数。严格遵循自包含容器规范，解密仅凭借文件自带的 `emkBlob` + 用户输入的 PIN，或脱机恢复码，消除错误 PIN 仍能解密文件的信任链漏洞。

### 2. 效能优化：全文件解密消除第二遍磁盘全量读
- **流式同步计算 SHA-256**：在 `FileObfuscator.ReadFullEncryptBody` 分块解密并写入明文磁盘文件的同时，使用 `IncrementalHash` 同步计算明文 SHA-256。
- **收益**：彻底消除解密完成后重新打开临时文件全盘读取计算哈希的磁盘 I/O，解密整体耗时降低近 40%~50%，显著减轻 SSD 写入与读取放大。

### 3. 存储路径与品牌统一
- **数据目录统一**：非便携模式存储路径由 `%APPDATA%\HideFiles` 统一规范为 `%APPDATA%\com.mcxiaoke\CarroCasket`；`ShellContextMenu` 提取图标与配置存储收口至同一路径；并在 `HideFilesConfig.DirPath` 中增加平滑升级逻辑，自动迁移旧目录中的 `config.json`。
- **品牌名称规范**：对外显示名统一为 `Carro Casket`（带空格）；中文名 `萝卜密匣` 保留常量但界面和命令行提示中不再混用。

### 4. 关于界面排版与两边留白优化
- **排版重构**：`MainWindow.xaml` 中关于页由原先靠左单侧延伸改为水平居中展示（`HorizontalAlignment="Center"`，`MaxWidth="600"`），并设置对称内边距与留白（`Margin="32,24"`），图标与标题居中，解决宽屏下右侧大片空置失衡的问题。

### 5. 任务取消控制（Cancellation）
- **全链路传递 CancellationToken**：`FileObfuscator.ObfuscateFile`、`RestoreFile`、分块读写循环、`BatchProcessor` 均增加 `CancellationToken` 支持。
- **界面与 CLI 响应**：
  - GUI：`MainViewModel` 引入 `CancellationTokenSource`，底部状态栏进度条旁新增“取消”按钮，支持在长任务或大文件处理中随时安全中止，并自动清理未完成的 `.tmp` 临时文件。
  - CLI：挂载 `Console.CancelKeyPress`，按 Ctrl+C 可立即优雅中断任务。
