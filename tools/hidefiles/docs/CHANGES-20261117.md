- **2026-11-17 21:21:02**：结构锁改为"失败安全"的原地写入与还原（审查报告 P0-2、P1-5，顺带 P1-3 的长度校验）：
  1. **写入回滚**：`ProtectInPlace` 先把全部锁定区原始字节读进内存（≤1MB，与文件大小无关），加密只作用于副本；写密文或 footer 任一步骤失败都在 `catch` 中用原始字节写回并 `SetLength(原长)`，不再留下"结构已加密但无 footer"的不可恢复文件。仍不复制整个文件，2GB/10GB 的处理耗时不受影响。
  2. **提交点判定**：footer 由 8 次小写入改为整段一次写入，写完用"文件长度 == 原长 + footer 长"且"尾部魔数正确"判定提交，未提交即回滚。
  3. **还原两阶段**：`RestoreInPlace` 先把所有区解密到内存并完成 CRC 校验，全部通过后才写回并截断 footer。此前是"边解密边写回"，中途失败后再重试会把已解密区再次 CTR 加密（自反）造成二次损坏。
  4. **长度一致性校验**：还原前校验 `BodyLength == OriginalLength`，可捕获截断/拼接类损坏；不一致直接拒绝，文件不动。
