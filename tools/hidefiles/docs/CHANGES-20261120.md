# 2026-11-20 变更摘要

## 13:30:32 右键菜单工作台定位重构、消除自动操作与弹窗竞态、未加密文件密名展示规范（批次 3）

### 1. 右键菜单重构：专注工作台定位与路径投递，杜绝自动处理
- **职责精简**：右键菜单不再执行任何自动加密或解密操作；移除第三项“打开 CarroCasket”，保留前两项专职用于快速定位不同工作台：
  - 项 1：“混淆工作台”：携带 `--tab struct` 参数打开 GUI 并选定混淆工作台；
  - 项 2：“加密工作台”：携带 `--tab secure` 参数打开 GUI 并选定加密工作台。
- **参数解析与导航解耦**：`ShellActionParser` 增加 `--tab` 参数支持并解析出 `TargetTab`，`ShellContextMenu` 清理历史残留子菜单。
- **彻底消除启动双重弹窗与闪烁**：右键菜单仅负责选定 Tab 并添加路径到列表，不再派发后台自动处理，启动过程统一由 `App.OnStartup` 驱动单次密码输入弹窗，根治了此前右键启动时密码框闪烁两次的问题。

### 2. 未加密与未解锁状态下文件名称展示规范
- **杜绝未加密文件的假密名**：针对未加密文件（Normal 状态），不再预先注入基于文件名哈希算出的密文名；【加密文件名】列清白规范显示为 `--`。
- **密码学语义自洽**：
  - 未加密文件：原始文件名清晰呈现，加密文件名显示为 `--`，绝不虚构密名；
  - 已加密文件（未解锁）：加密文件名显示磁盘真实密文名，原始文件名明确标注 `(未解锁)`，清晰表达因未输入密码而无法读取内部元数据；
  - 已加密文件（已解锁）：输入密码后秒级解密出真实原名，与密文文件名形成对称对照。

## 13:05:52 文件名混淆与结构加密展示解耦、原始名与加密名双向即时对照（批次 2）

### 1. 文件名混淆预测算法公共化与解耦
- **算法抽取**：在 `FileObfuscator` 增加公共静态方法 `PredictTargetFileName(originalFileName, length, config)`，将根据原文件名、长度哈希与伪装规则组生成目标文件名的逻辑解耦。
- **正向调用复用**：`ObfuscateFile` 统一复用该方法，消除多处文件名哈希规则冗余。

### 2. FileItemModel 增强与双向名称展示属性
- **模型扩展**：`FileItemModel` 新增 `EncryptedFileName` 属性，与 `OriginalFileName`、`FileName`、`Status` 深度联动。
- **展示逻辑规范**：
  - `DisplayOriginalFileName`：未处理文件直接取原名；已混淆/已加密文件取解密后的原始文件名（未解锁时标注 `(未解锁)`）；
  - `DisplayEncryptedFileName`：未处理文件根据当前伪装规则预测生成（如 `hf_xxxx.dat`）；已处理文件显示实际磁盘密文文件名。

### 3. GUI 列表列定义升级与即时对照呈现
- **双列映射设计**：混淆工作台与加密工作台 DataGrid 统一升级为【原始文件名】（粗体展示）与【加密文件名】（辅助色展示）两列。
- **全生命周期自适应**：
  - 拖拽未加密文件：原始文件名清晰可见，同时右侧即时预览加密后的伪装名；
  - 拖拽已加密文件：依靠启动已解锁的 Session Key，瞬间解密填充原始文件名，与当前磁盘加密名形成直观对照；
  - 加解密完成：两列名称与状态徽章丝滑切换，提供完整、对称的双向视图。

## 13:01:43 GUI 启动密码对话框、Session 会话凭据常驻缓存与按需弹窗回退（批次 1）

### 1. GUI 启动自动验证主密码与会话状态初始化
- **启动弹窗交互**：在 `App.OnStartup` 中检测到已配置密码时，应用启动后自动弹出主密码验证对话框，要求用户输入密码解锁会话。
- **环境隔离保障**：增加非自动化/非测试环境判定（`HideFilesConfig.DataDirOverride == null`），确保右键静默处理与 UiQa 自动化验收测试不受模态对话框干扰挂起。

### 2. 进程内会话凭据（SessionPin / SessionMasterKey）常驻缓存与按需回退
- **内存生命周期管理**：验证通过后解密主密钥 `MasterKey` 并在进程内存中常驻缓存（`_sessionMasterKey` 与 `_sessionPin`），同时置位 `IsSessionUnlocked`。
- **优先缓存与零打断操作**：`EnsureEncryptionReady` 与 `EnsureRestoreCredential` 优先使用会话内已缓存的凭据，后续所有加解密操作无需重复输入密码；若用户启动时取消解锁，则保留原有在点击操作时按需弹出密码框的逻辑。
- **已加载文件元数据即时补全**：会话解锁后自动触发后台任务，快速解密嗅探列表中已混淆/已加密文件的原始文件名并更新界面。

### 3. 状态栏会话解锁状态展示与快捷切换
- **状态栏图标与按钮**：主界面底部状态栏新增 `[ 🔓 已解锁 ]` / `[ 🔒 未解锁 ]` 状态指示按钮与 ToolTip 说明，支持一键锁定或点击弹窗重新解锁。
- **密码管理同步**：设置新密码、修改密码或清除密码时，状态与会话密钥同步更新/销毁。
