# 变更记录 2026-11-21

## 2026-11-21 10:36:25 - 新增「工具」标签页与文件名混淆功能

- **界面重构**：
  - 新增「工具」Tab（位于加密与设置之间，Tab 顺序：混淆 / 加密 / 工具 / 设置 / 关于）。
  - 将原设置页中的「目录名伪装」移入「工具」页，设置页精简为 5 个核心设置卡片。
  - 「工具」页采用多分组卡片设计，每个功能一个 Group：
    - **Group 1: 目录名混淆**：提供说明、包含子目录复选框、混淆目录名按钮、还原目录名按钮。
    - **Group 2: 文件名混淆**：提供说明、包含子目录复选框、保留扩展名复选框、混淆文件夹 / 还原文件夹 / 混淆文件 / 还原文件操作按钮。
- **核心算法（HideFiles.Core）**：
  - 提取名称混淆通用底层 `NameObfuscator`（基于 Base32 + 字节掩码 + CRC16 校验尾 + v2 格式标记 + `_hf_` 前缀），保持与既有目录名混淆完全兼容。
  - 新增 `FileNameObfuscator`：
    - 算法与目录名完全一致，保证确定性、幂等性与可逆性。
    - 支持整名混淆（隐藏扩展名与文件类型）与保留扩展名两种模式。
    - 还原端自适应智能识别整名混淆与保留扩展名格式，校验失败或非本工具混淆名称安全跳过。
    - 自动忽略 Windows 系统文件（`desktop.ini`、`thumbs.db` 等）。
- **命令行工具（HideFiles.Cli）**：
  - 新增命令 `CarroCasketCli fn-hide <路径...> [--keep-ext]` 与 `CarroCasketCli fn-unhide <路径...>`，支持针对文件夹或单个/多个具体文件批量执行。
- **自动化测试**：
  - 新增 `FileNameTests` 单元测试（8 项），覆盖幂等性、整名混淆/还原、保留扩展名混淆/还原、嵌套目录批量处理、冲突处理、CRC 校验等。
  - 更新 `UiQa` 自动化界面验收测试，通过 153 项单元测试与真实渲染界面测试。
