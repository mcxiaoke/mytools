# takeshot

极简命令行快速拍照工具。调用后默认调用系统/USB 摄像头拍摄 1 张 1080p 照片存入系统临时目录，支持连拍、定时、持续时间、指定输出位置与快速分辨率切换。

## 使用方式

已配置 `takeshot.cmd` 于 `PATH` 中，可直接在任意终端运行：

```powershell
# 1. 极简默认：无参数拍照 1 张 (1080p) 保存到临时目录 (耗时约 2.3 秒)
takeshot

# 2. 极速模式：画面脱离黑屏立即拍照 (耗时更短)
takeshot --fast

# 3. 延时 3 秒后拍照 (给自己准备时间)
takeshot -w 3

# 4. 连拍 5 张，每隔 1.5 秒拍一张
takeshot -n 5 -i 1.5

# 5. 持续抓拍 10 秒，每隔 0.5 秒一张
takeshot -d 10 -i 0.5

# 6. 指定保存目录或文件名
takeshot -o "D:\Photos"
takeshot -o "D:\Photos\my_shot.jpg"

# 7. 指定分辨率 (如 720p, 4k 或自定义 1280x720)
takeshot --res 720p

# 8. 静默模式 (仅打印输出路径，方便脚本管道串联)
takeshot -q
```

## 核心优化要点

1. **构造期直接注入 1080p + MJPG**：
   * 避免了在开流后多次调用 `cap.set()` 导致 Windows DirectShow 滤镜图发生 3 次反复销毁与重建（节省约 2.5 秒）。
2. **智能硬件预热**：
   * 移除无意义的 `sleep`，动态检测有效帧与黑帧收敛，并在拍照时直接复用就绪帧，避免二次等待（节省约 3.5 秒）。
3. **物理硬件启动限制**：
   * 冷启动时总耗时约 2.2~2.3 秒，其中约 1.0 秒为 USB 摄像头感光芯片硬件通电与固件开流交付第一帧数据的物理下限。连拍模式后续每张仅需约 45ms。
